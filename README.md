## 🔬 Research Focus

Exploring quantum computing and theoretical physics, with a focus on quantum error correction (QEC), open quantum systems, passive and autonomous error mitigation, Fibonacci-time dynamics, photonic quantum architectures, and mathematical field theory.

## 🚀 Featured Repositories

These projects explore related ideas from different angles—from software prototypes and simulators to photonic frameworks and theoretical research. Each repository's README contains its detailed documentation, implementation notes, and usage information.

### Quantum error correction and autonomous healing

#### 1. [HMQTF — Hyper-Mirror Quantum Theory Field](https://github.com/synthesis496/hmqtf)
A Python framework for measurement-free, passive autonomous qudit error correction. It explores Lindblad open-system dynamics, Fibonacci-time modulation, anti-cascade geometry, mirror-parity operators, and limit-cycle behavior. The repository includes a core engine, demos, tests, and benchmarks.

#### 2. [AQEH32 — Hybrid Quantum Error Correction & Passive Healing Simulator](https://github.com/synthesis496/AQEH32)
A Python simulator for hybrid QEC in five-level qudit systems. It combines symmetry-inspired decoding with passive Lindbladian healing and Fibonacci-timed operation across a multi-site network.

#### 3. [Passive Autonomous QEC](https://github.com/synthesis496/Passive_Automous_QEC)
An experimental Python prototype investigating passive state stabilization using Fibonacci-tempered timing, mirror/parity cancellation, and dissipative attractor dynamics. It includes JAX and NumPy implementations; the project README describes it as exploratory rather than a production QEC system.

#### 4. [SAH_Quantum — Symmetry-Autonomous Healing Quantum Suite](https://github.com/synthesis496/SAH_Quantum)
A Python simulation framework for passive error mitigation and autonomous state healing. Its architecture brings together Fibonacci-time dynamics, symmetry-based diagnostics, state-walking correction paths, and Qiskit/Cirq integration.

### Photonic quantum and open-system frameworks

#### 5. [ShrPP_FT_PIC — SHRPPCore](https://github.com/synthesis496/ShrPP_FT_PIC)
An open-source Python framework for simulating open quantum systems, with Fibonacci-driven dynamics, folding and mirror symmetries, and state-healing operators. The repository includes validation tests, performance benchmarks, and examples.

#### 6. [Y_always_Me — Honeycomb Photonic Quantum Field Architecture](https://github.com/synthesis496/Y_always_Me)
A Python framework exploring a honeycomb photonic quantum-field architecture, infinite-domain modeling, Fibonacci-time dynamics, and autonomous field stabilization. See the project README for its stated design and validation approach.

### Theoretical physics

#### 7. [FVSF_THEORY — Fibo Vortex Spiral Space Field Theory](https://github.com/synthesis496/FVSF_THEORY)
A research repository containing a theoretical manuscript, supporting derivations, and proposed predictions built around Fibonacci-time self-similarity and geometric field structures. The repository includes a reading guide and supplementary materials; its claims are presented as research proposals for examination and testing.
